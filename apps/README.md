# Lineage Apps

Standalone, real-life applications built on the Lineage framework.

## Available Apps

- `deepseek-payments-agent` - DeepSeek accounts-payable agent: spending authority as the guard budget, a reasoning-model fraud reviewer, human approval for large payments, and a bank that only honors matching guard approvals.
- `guarded-agent` - Claude-powered incident-response agent where every model turn and tool call passes through the guard.
- `guard-server` - HTTP policy gate and tamper-evident audit trail for AI agents.
- `governance-ops` - Governance operations console with graveyard integration.
