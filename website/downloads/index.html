Lineage …

Prebuilt, statically linked binaries for Linux x86-64: they run on any distribution with no dependencies. On other platforms, install from source with Cargo.

curl -fsSL https://lineagrs.tech/install.sh | sh
cargo install lineage-rs

The script downloads the release below, checks its SHA-256 checksum, and installs lineage and guard-server to ~/.local/bin. Read it first.
